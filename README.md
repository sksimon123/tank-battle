# 坦克大战 (Tank Battle)

使用原生 HTML5 Canvas 编写的经典坦克大战复刻，**单文件、零依赖**，直接用浏览器打开即可游玩。

## 🎮 玩法

- 控制己方坦克，消灭每一关的 **20 辆** 敌方坦克
- 保护下方的基地（🦅 老鹰），基地被摧毁则游戏结束
- 子弹可以打碎砖墙开路；钢铁墙只有满级火力才能击穿
- 第 4、11、18 辆敌军坦克（闪烁）被击毁后会掉落道具
- 关卡会循环并越来越难（敌军速度、装甲坦克数量随关卡提升）

## ⌨️ 操作

| 按键 | 功能 |
| --- | --- |
| `WASD` / `方向键` | 移动 |
| `空格` / `J` | 开火 |
| `P` | 暂停 |
| `M` | 静音 |
| `Enter` / 点击画面 | 开始 / 重新开始 |

移动端打开时会自动显示虚拟方向键与开火按钮。

## ✨ 道具

| 道具 | 效果 |
| --- | --- |
| ⭐ 星星 | 火力提升（最多 3 级：高速子弹 → 双弹 → 击穿钢墙） |
| 🧨 手雷 | 消灭场上所有敌军坦克 |
| 🛡 头盔 | 12 秒无敌护盾 |
| ❄ 时钟 | 冻结敌军 10 秒 |
| ⛏ 铁锹 | 基地砖墙变钢墙 20 秒 |
| 🎖 坦克 | 生命 +1 |

## 🗺️ 地形

- 🧱 砖墙：可被子弹摧毁
- ⬜ 钢墙：只有满级火力可摧毁
- 🌊 水面：坦克无法通过，子弹可以飞过
- 🌳 树丛：可以穿过，能隐藏坦克
- 🧊 冰面：坦克会打滑
